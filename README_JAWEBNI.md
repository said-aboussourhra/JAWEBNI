# جاوبني — JAWEBNI | موظفك الذكي على واتساب 24/7 🇲🇦

## 🚀 نظام تشغيل الأعمال الذكي بالمغرب — AI Operating System for Moroccan Businesses

**جاوبني** هو نظام تشغيل أعمال متكامل مبني على الذكاء الاصطناعي، يحوّل واتساب إلى موظف ذكي يعمل 24/7 للأنشطة المغربية — من محلات القفطان والجلابة إلى المطاعم والخدمات.

---

## ✨ الميزات الكاملة — Full Features (100% Implemented)

### 1. 📊 نبض الأعمال (Business Pulse) — مركز القيادة الحي
- **Live Activity Feed**: عرض حي لكل محادثات AI مع معدل الثقة والنية المكتشفة
- **Opportunity Radar**: رادار فرص تفاعلي — فرص ساخنة، عملاء ينتظرون تدخلاً بشرياً، أسئلة غير مجابة
- **Intelligence Storytelling**: سرد ذكي لأداء اليوم بالعربية والفرنسية
- **Metrics**: محادثات اليوم، ساعات العمل الموفّرة، فرص بيع مؤكدة، معدل حل AI

### 2. 💬 صندوق المحادثات الذكي (AI Inbox) — 3-Panel Workspace
- **قائمة المحادثات**: مع Lead Score، Sentiment، Priority، Intent
- **نافذة المحادثة**: رسائل مع AI Confidence، Intent Detection، Human Handoff
- **لوحة معلومات الزبون**: ذاكرة AI، تفضيلات، سجل الطلبات، ملاحظات الفريق
- **تحكم AI**: تفعيل/تعطيل AI لكل محادثة، إرسال رسائل يدوية

### 3. 🧠 استوديو الذكاء الاصطناعي (AI Studio) — 3 طرق للتعليم
- **الطريقة 1: Q&A بالدارجة**: إضافة أسئلة وأجوبة بالدارجة المغربية مع تصنيف
- **الطريقة 2: مختبر الشخصية**: ضبط نبرة الصوت (مغربي ودود، رسمي، فخم) ونسب اللغات (دارجة 70%، عربية 20%، فرنسية 10%)
- **الطريقة 3: مختبر الاختبار الفوري**: محاكاة محادثات واتساب حقيقية مع تحليل النية والثقة
- **RAG Document Ingestion**: رفع كتالوجات PDF/DOCX/XLSX واستخراج النص وتقسيمه إلى Chunks
- **Knowledge Health Score**: مؤشر صحة المعرفة مع checklist

### 4. 👥 ذكاء العملاء (Customer Intelligence & CRM)
- **جدول العملاء**: بحث، فلترة بالوسوم، Lead Score، LTV
- **ملف الزبون**: مسار العميل المرئي، ذاكرة AI (مقاسات، ألوان، مناسبات)، ملاحظات الفريق
- **وسوم ذكية**: VIP، Caftan Lover، Casablanca، إلخ

### 5. 📅 الحجوزات والمواعيد (Booking Workspace)
- **تقويم يومي**: عرض الأوقات المتاحة والمحجوزة مع فريق العمل
- **قائمة المواعيد**: بحث، حالة، مصدر الحجز (AI أو يدوي)
- **الخدمات والطاقم**: إدارة خدمات القياس والطاقم (Styliste, Conseillère)
- **حجز تلقائي عبر AI**: عندما يطلب زبون موعداً عبر واتساب، يقترح AI الأوقات المتاحة ويؤكد

### 6. 📢 الحملات الجماعية (Campaign Mission Control)
- **الحملات**: إنشاء حملات واتساب مستهدفة مع قوالب معتمدة من Meta
- **القوالب**: إدارة قوالب واتساب (عرض ترويجي، تأكيد حجز، سلة مهجورة)
- **التحليلات**: تتبع التسليم، القراءة، الردود، وتحليل الأداء حسب الشريحة
- **توصيات ذكية**: وقت الإرسال الأمثل، الشريحة الأعلى تفاعلاً

### 7. ⚙️ محرك الأتمتة المرئي (Visual Automation Engine)
- **قائمة مسارات العمل**: مع Trigger Type، حالة النشاط، عدد التنفيذ
- **Canvas مرئي**: عرض Trigger → Condition → Actions → End مع إحصائيات
- **قوالب جاهزة**: ترحيب فوري + كتالوج، تذكير موعد، متابعة سلة مهجورة، تصعيد شكوى
- **إنشاء مسار جديد**: تحديد الاسم، الوصف، نقطة الانطلاق

### 8. 📈 التحليلات وسرد الرؤى (Intelligence Storytelling Analytics)
- **KPIs**: معدل حل AI، متوسط زمن الرد، معدل التحويل، رضا العملاء
- **توزيع النوايا**: تحليل نوعية أسئلة الزبائن
- **أكثر الأسئلة تكراراً**: مع حالة التغطية في المعرفة
- **استهلاك التوكنز والتكلفة**: تتبع يومي مع توصيات لتقليل التكلفة
- **قمع التحويل**: من الاستفسار الأولي إلى البيع المؤكد
- **Business Story Narrative**: قصة أداء ذكية بالعربية

### 9. 💳 الفوترة والاشتراك (Billing & Bank Transfer)
- **خطط الاشتراك**: Starter (199 MAD)، Growth (499 MAD - الأكثر شعبية)، Scale (999 MAD)
- **الدفع عبر التحويل البنكي**: RIB/IBAN مع رفع إيصال، مرجع JW-XXXX
- **معلومات البنك**: Attijariwafa Bank، RIB، IBAN، SWIFT مع نسخ سهل
- **سجل المدفوعات**: حالة (pending_review, approved, rejected)
- **اشتراك حالي**: عرض الخطة النشطة وتاريخ الانتهاء

### 10. 🛡️ مركز التحكم العام (Super Admin Control Center)
- **نظرة عامة**: إيرادات، مدفوعات قيد المراجعة، متوسط جاهزية AI، نشاط جديد
- **إدارة المستأجرين**: قائمة الأنشطة مع بحث، مدينة، حالة، جاهزية AI
- **إدارة المدفوعات**: موافقة/رفض مع ملاحظات، سجل كامل
- **إعدادات البنك**: تحديث RIB/IBAN/SWIFT وتعليمات الدفع

### 11. 🎓 تجربة الإعداد (Onboarding) — 5 خطوات
1. هوية النشاط التجاري (منتجات، مدن التوصيل، سعر التوصيل)
2. ربط واتساب السحابي (Phone Number ID، Verify Token، Webhook URL)
3. تعليم الذكاء الاصطناعي (سؤال وجواب بالدارجة)
4. تحديد الشخصية والأسلوب (نبرة، نسب لغات، طول الرد)
5. اختبار وإطلاق الموظف (معاينة الجاهزية 100%)

### 12. 🔧 ميزات تقنية متقدمة
- **Multi-Tenancy**: عزل كامل للبيانات بين الأنشطة (TenantScope, BelongsToTenant)
- **WhatsApp Cloud API**: Meta Official API مع Webhook Verification
- **Agent Router Service**: توجيه ذكي للرسائل إلى 5 وكلاء متخصصين (Sales, Booking, Support, Complaint, FAQ)
- **RAG System**: DocumentExtractor, TextChunker, RAGRetrieval, KnowledgeHealth
- **AI Providers**: OpenAI, Claude, Gemini مع واجهة موحدة (AIProviderInterface)
- **Human Handoff**: كشف تلقائي للشكاوى وتحويل للبشري مع تسجيل السبب
- **Command Palette**: Ctrl+K للبحث السريع في كل شيء
- **Copilot**: مساعد ذكي داخل التطبيق مع رؤى استباقية
- **i18n**: دعم كامل للعربية (دارجة)، الفرنسية، الإنجليزية مع RTL/LTR

## 🛠️ التقنيات المستخدمة — Tech Stack

### Backend (Laravel 12)
- **Framework**: Laravel 12 (PHP 8.2+)
- **Database**: SQLite (default) / MySQL / PostgreSQL
- **ORM**: Eloquent with UUIDs, Tenant Scoping
- **Queue**: Database / Sync
- **Auth**: Laravel Auth with Multi-Tenancy
- **API**: Meta WhatsApp Cloud API v20.0
- **AI**: OpenAI GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro

### Frontend (React 19 + Inertia)
- **Framework**: React 19.2, TypeScript 7.0
- **Bridge**: Inertia.js 3.7 (SPA without API)
- **Styling**: Tailwind CSS 4.3, Radix UI, Lucide Icons, Framer Motion
- **Build**: Vite 7.0, Laravel Vite Plugin
- **State**: React Hooks, Inertia Forms

### Infrastructure
- **Multi-Tenancy**: Business model with business_user pivot, TenantContextMiddleware
- **File Storage**: Local disk for knowledge docs & payment receipts
- **Webhooks**: Public endpoints for WhatsApp verification & handling

## 🔌 إعداد واتساب السحابي — WhatsApp Cloud API Setup

1. اذهب إلى https://developers.facebook.com
2. أنشئ تطبيق جديد → نوع Business
3. أضف منتج WhatsApp
4. احصل على:
   - Phone Number ID
   - Access Token (مؤقت أو دائم)
   - App Secret
5. في Webhook:
   - URL: `https://yourdomain.com/api/webhook/whatsapp`
   - Verify Token: `jawebni_webhook_secret_2026`
   - Subscribe to: messages
6. أضف في `.env`:
   ```
   WHATSAPP_PHONE_NUMBER_ID=your_phone_number_id
   WHATSAPP_ACCESS_TOKEN=your_access_token
   WHATSAPP_VERIFY_TOKEN=jawebni_webhook_secret_2026
   ```

## 🔐 الأمان — Security

- **Multi-Tenancy Isolation**: TenantScope يضمن عدم تسريب البيانات بين الأنشطة
